## 2. Functional Unlocks & Non-Root Crash Safety

- **ART Hidden API Bypass (`bypass_art_hidden_api`)**: On locked Android 17 (`SDK 37`), user-installed `untrusted_app` builds cannot resolve framework hidden fields/methods (`CaptureRequest.mLogicalCameraSettings`, `mSettings`, `CaptureResult.mResults`, `CameraCharacteristics.mProperties`, `CameraMetadataNative`) accessed by `libmcf-jni.so` during `Mcf.native_construct()`. Bundling `org.lsposed.hiddenapibypass:hiddenapibypass:6.2` (`patches/hiddenapibypass_smali`) and invoking `HiddenApiBypass.addHiddenApiExemptions("L")` at the start of `CameraApp.onCreate()` exempts both the UI process and `:postProcService` without root.
- **`DeveloperMenu.isMenuEnabled()Z`** (`smali/com/motorola/camera/instrumentreport/DeveloperMenu.smali:40`): On production `user` builds (`ro.boot.is_production` != `"false"`), Moto sets `mDebug = Boolean.FALSE`, hiding `@string/settings_list_about_debug_key` in `GeneralSettingsFragment.smali:1100`. Patching `Boolean;->FALSE` to `Boolean;->TRUE` unlocks the built-in Developer UI (`DebugPreferencesFragment` / `DebugUiPreference`) and `SettingsManager` editor while preserving the `isUserAMonkey()` guard.
- **`McfJsonConfig.getConfiguration()[B`** (`smali/com/motorola/camera/fsm/camera/states/runnables/McfJsonConfig.smali:40-46`): Removing the `Util.TEST_BUILD` branch allows `log.tag.mcf.override.config` (`MCF_OVERRIDE`) runtime config overrides without enabling `Util.TEST_BUILD` globally (which was verified in `FileName.smali` and `TextureManager$$ExternalSyntheticLambda1.smali` to add `_FALLBACK`/`_NR`/`_SM` suffixes to saved photo filenames and enable `DebugIdComponent` screen overlays).
- **Offline AI model bundling (`local_ai_models_fallback` + `ensureUncompressedAssets`)**: `LocalAiModelFallback.smali` maps all 9 stock `ContentAiProviderHelper$Model` enum names (`GESTURE_AUTO_CAPTURE_TFLITE_MODEL`, `SCENE_DETECTION_TFLITE_MODEL`, `MOT_SCENE_DETECTION`, `SMILE_DETECTION_TFLITE_MODEL`, `EYE_CONTOUR_TFLITE_MODEL`, `DOC_SCAN_MODEL`, `DOC_SHADOW_REMOVAL_MODEL`, `SLIDE_SCAN_MODEL`, `SLIDE_AUTO_CAPTURE_MODEL`) to `assets/ai_models/*.bin` stored uncompressed (`method=0` via `apktool.yml` `doNotCompress`), verified live on `ctwo` with `LocalAiModelFallback` + `tflite` XNNPACK initialization and zero `Permission Denial`.
- **Dynamic Feature `0x81` ARSC Preservation (`arsc_merge.mjs` `--merge-arsc-from`)**: `MotCamera4.apk` embeds package `0x81` (`com.motorola.camera3.feature_adobe_scan`) in `resources.arsc` alongside `0x7f`; `apktool 3.0.3` drops `0x81` during decompile/rebuild, causing `Resources$NotFoundException: Resource ID #0x8101000e` (`powered_by_adobe_scan_icon` in `AdobeScanComponent.PreviewArea`). Merging `0x81` back into `resources.arsc` (appending missing UTF-8 strings without shifting styled string indices) restores `Escáner` (`Adobe Scan`) without modifying `g/X.smali` hardcoded IDs.
- **Non-privileged `SecurityException` audit**:
  - `Camera.smali:837-858` (`IActivityManager.mSetReserveFreeKbytesWhitelist`) catches `SecurityException`, `IllegalAccessException`, `InvocationTargetException`.
  - `ContentAiProviderHelper.smali:502-635` catches `Exception` around `ContentResolver.query()` and `openAssetFileDescriptor()`.
  - `PackageUtility.smali` catches `NameNotFoundException` across `getContentAiPackageName()` and `getImagerTuningName()`.
